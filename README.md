# flugschein-training

Offline PPL(A) theory practice for the nine TCAA syllabus subjects — 90 original multiple-choice questions, plain static files, no build step, no accounts, no network.

Open `index.html` in a browser. Tests: `node --test "test/*.test.mjs"`.

Public, app-only mirror. Research notes and email history stay in the private `eminogrande/flugschein` repository.
